# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/) (v2.1).

Full text: [CODE_OF_CONDUCT.md in the repository](https://github.com/Pooya-Ideas/markitdown-cli/blob/main/CODE_OF_CONDUCT.md).

## Summary

- Be kind and respectful.
- No harassment, trolling, or publishing private information.
- Report concerns privately to the maintainers.

Enforcement may include warnings up to permanent bans for repeated or severe violations.
