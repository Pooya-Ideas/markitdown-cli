# Security

## Supported versions

| Version | Supported |
|---------|-----------|
| 2.x | Yes |
| < 2.0 | No |

## Reporting a vulnerability

**Do not open a public issue.**

1. Prefer [Private vulnerability reporting](https://github.com/Pooya-Ideas/markitdown-cli/security/advisories/new), or
2. Contact the repository owner via their GitHub profile.

Include description, reproduction steps, affected versions, and impact.

We aim to acknowledge within **7 days** and update within **14 days**.

Full policy: [SECURITY.md](https://github.com/Pooya-Ideas/markitdown-cli/blob/main/SECURITY.md).
